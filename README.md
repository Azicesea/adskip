# adskip · 跳过广告

一个自用的极简安卓开屏广告跳过工具。用无障碍服务盯着屏幕，看到「跳过」「跳过 5」「关闭广告」这类按钮就点掉，不联网、不收集数据、不上传任何东西。

> 只给自己用，没有上架应用商店，也不打算上架。

## 它能做什么

- **开屏广告自动跳过**：应用切到前台后 20 秒内高频扫描，抓到「跳过 / 跳过广告 / skip」之类的按钮就点。按钮带倒计时（如「跳过 5」）时会隔 2.5 秒重试，一轮最多动三次手。
- **角落关闭键**（激进模式，默认关）：有些广告的关闭键没有文字，只有一个「×」。打开后会尝试右上、右下角的小按钮，可能误点，建议按需开。
- **盲点兜底**（默认关）：如果整个广告是一张图、无障碍树里根本没有按钮，就按坐标点右上/右下角。
- **弹窗兜底**：识别「開 / ¥ / 红包 / 到账」这类诱导弹窗，先找关闭键，找不到再按返回。微信、QQ、TIM、支付宝、钉钉、企业微信里不生效。
- **应用选择**：默认所有应用生效，也可以只勾选想生效的应用（支持搜索）。
- **最近动作**：看得见它刚在哪几个应用动过手。
- **诊断模式**：把当前页面的无障碍节点树导出成文本，排查「这个广告为什么跳不掉」。

## 怎么用

1. 装好 APK，打开应用。
2. 点「去开启无障碍服务」，在系统设置里找到「跳过广告」并打开。**不开这个什么都不会发生**，这是系统限制。
3. 回应用里把「启用自动跳过」打开，完事。
4. 后台被系统杀掉后无障碍会被关，需要重新打开一次——安卓老问题，App 没有权限自己唤醒。

## 已知限制

- 只能跳过**能被无障碍服务看到**的按钮。如果广告把「跳过」画在图片里，无障碍树里没有这个节点，就点不到（这时可以试盲点兜底）。
- 游戏、部分 WebView 页面拿不到无障碍树。
- 各家的开屏样式千差万别，规则是按实际遇到的样式一点点补的，不保证覆盖所有应用。
- 无障碍服务本身有一定隐私敏感性：本应用只读窗口结构用来找按钮，不读输入框内容、不联网、不写日志到外部。

## 构建

需要 JDK 17 + Android SDK（platform 34、build-tools 34.0.0）。

```bash
git clone https://github.com/Azicesea/adskip.git
cd adskip
# local.properties 里写 sdk.dir=<你的 Android SDK 路径>
./gradlew assembleDebug   # 或者用本机 gradle: gradle -p . assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 项目结构

```
app/src/main/java/com/dafeiyu/adskip/
  MainActivity.kt              # 界面：开关、计数、应用选择、诊断导出
  SkipAccessibilityService.kt  # 核心：轮询窗口、找按钮、点击、弹窗兜底
  Prefs.kt                     # 设置存储
app/src/main/res/xml/
  accessibility_service_config.xml
  file_paths.xml               # 诊断文件的 FileProvider 路径
```
